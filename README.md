# ControlFlip — переключатель раскладки для macOS

**Russian ↔ English keyboard layout switcher and wrong-layout text correction for Mac.**

[**Скачать ControlFlip 1.2.3 для macOS — DMG**](https://github.com/BezNik2006/ControlFlip/raw/refs/heads/main/Downloads/ControlFlip-1.2.3-Universal.dmg) · Apple Silicon и Intel · macOS 13+

ControlFlip — бесплатная программа для исправления текста, набранного в неправильной раскладке на Mac. Коротко нажмите назначенную клавишу: `ghbdtn` превратится в `привет`, а `руддщ` — в `hello`. После исправления переключается русская или английская раскладка, чтобы вы сразу продолжили печатать на нужном языке.

- **Последнее слово или выделенный текст.** Исправляйте слово перед курсором либо сразу весь выделенный фрагмент.
- **Свои горячие клавиши.** По умолчанию — одиночное нажатие левого Control. Можно назначить своё сочетание с учётом левой и правой клавиши.
- **Исключения для приложений.** Выберите программы, в которых исправление нужно отключить.
- **Автозапуск при входе в macOS.** Включается и отключается в настройках.
- **Приложение строки меню.** Компактный значок **а/я**, обработка текста локально и установщик для Apple Silicon и Intel.

## English

ControlFlip is a native macOS keyboard layout switcher and text correction utility for Russian and English. If you typed a word with the wrong keyboard layout, press a customizable keyboard shortcut to convert the last word or selected text. The input language then switches to match the corrected text.

Use a single left Control tap by default, or record your own hotkey. Features include application exclusions, launch at login, a menu bar icon, and a Universal DMG for Apple Silicon and Intel Macs running macOS 13 or later. Text is processed locally and is not sent over the network.

## Альтернатива Punto Switcher и Caramba Switcher для Mac

Если вы ищете аналог Punto Switcher (PuntoSwitcher) или Caramba Switcher («Карамба Свитчер») для macOS, ControlFlip подойдёт для исправления раскладки по горячей клавише: русского и английского текста, последнего слова или выделенного фрагмента. Исправление запускаете вы сами; автоматического определения языка и замен во время набора нет.

**Looking for a Punto Switcher or Caramba Switcher alternative for Mac?** ControlFlip focuses on manual hotkey-based keyboard layout conversion, then switches the input language for further typing.

## Установка

Требуется macOS 13 или новее. Один DMG содержит приложение для Apple Silicon и Intel.

1. Скачайте [ControlFlip 1.2.3 — Universal DMG](https://github.com/BezNik2006/ControlFlip/raw/refs/heads/main/Downloads/ControlFlip-1.2.3-Universal.dmg). Контрольная сумма SHA-256 находится в [Downloads/SHA256SUMS.txt](Downloads/SHA256SUMS.txt).
2. Откройте DMG и перетащите ControlFlip в «Программы». Завершите предыдущую версию перед заменой.
3. Запустите приложение из «Программ». Если macOS блокирует открытие, после попытки запуска откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** и подтвердите запуск.
4. При первом запуске ControlFlip сам запросит доступ. Если доступ отсутствует позже, нажмите верхнюю строку **«Нет доступа · нажмите, чтобы разрешить»** в меню **а/я**. В **Конфиденциальность и безопасность → Универсальный доступ** включите ControlFlip. Это разрешение пользователь выдаёт самостоятельно; установщик не может включить его автоматически. Если запись отсутствует, добавьте приложение кнопкой «+» из «Программ».
5. Добавьте русскую и английскую раскладки в настройках клавиатуры macOS.

Бесплатные выпуски используют постоянный сертификат автора. Нотариальное заверение Apple отсутствует, поэтому macOS может показывать предупреждение при первом запуске. Устанавливать сертификаты или закрытые ключи на компьютерах пользователей не нужно. Подробнее о первом открытии — в [инструкции Apple](https://support.apple.com/102445).

## Использование

Наберите `ghbdtn` в «Заметках», коротко нажмите и отпустите левый Control — получится `привет`, и раскладка переключится на русскую. Следующие символы вы уже будете набирать по-русски. В обратную сторону: `руддщ` → `hello`, после исправления включается английская раскладка.

Если текст выделен, назначенная клавиша исправляет весь выделенный фрагмент. Без выделения исправляется последнее слово перед курсором; пробелы после него сохраняются. Для собственного сочетания действие то же: нажмите назначенные клавиши, чтобы исправить текст и сменить язык дальнейшего набора. Сам по себе набор текста не запускает автоматические замены.

В **а/я → Настройки → Записать сочетание** можно задать свою клавишу, клавишу с модификаторами, один или несколько модификаторов либо двойное нажатие модификатора. Левая и правая стороны различаются. Два Shift одновременно и двойное нажатие одного Shift — разные варианты. Некоторые системные сочетания перехватывает macOS. Если назначить букву без модификаторов, она будет запускать исправление вместо ввода.

В тех же настройках доступны исключения программ и **Запускать при входе в macOS**. При первом запуске установленного приложения ControlFlip один раз запрашивает автозапуск. Состояние читается из macOS; отключённый пользователем автозапуск самопроизвольно не включается.

## Доступ

При первом запуске без доступа ControlFlip автоматически показывает системный запрос и открывает настройки Универсального доступа. При следующих запусках отдельные окна сами не появляются: если доступ отсутствует, верхняя строка меню показывает **«Нет доступа · нажмите, чтобы разрешить»**. Нажмите её, чтобы повторить запрос и открыть настройки macOS.

После выдачи разрешения приложение само повторяет подключение клавиатуры; строка состояния обновляется. Отдельных пунктов разрешения доступа, диагностики и перезапуска в меню нет. Изменение сочетания или включение исправления не скрывает сообщение об отсутствующем доступе.

Переход со старых временно подписанных тестовых сборок на постоянную подпись может потребовать повторной выдачи разрешения. Приложение не удаляет имеющуюся запись доступа и не обходит решение macOS.

Постоянная подпись сохраняет идентичность приложения между выпусками. Проверка сохранения реального разрешения после обновления пока не завершена; обещать отсутствие повторных запросов на всех версиях macOS нельзя. Внутренние правила распознавания подписанных обновлений описаны в [документации Apple](https://developer.apple.com/library/archive/technotes/tn2206/).

## Приватность и ограничения

- Приложение обрабатывает ввод локально, не отправляет текст в сеть и не записывает его на диск. В оперативной памяти временно хранится контекст до 4096 символов UTF-16.
- В полях паролей и при защищённом вводе исправление не выполняется.
- При замене временно используется буфер обмена. После вставки он восстанавливается, если другая программа не успела изменить его содержимое.
- Сложное форматирование выделенного текста может измениться. Некоторые редакторы требуют выделить фрагмент для исправления.
- После перемещения курсора, смены окна и щелчка мышью временный контекст очищается.

## Сборка и GitHub

Нужны Apple Command Line Tools или Xcode и Python 3. Внешних зависимостей Swift нет. `./test.command` запускает 65 проверок; `./build.command` собирает обе архитектуры и объединяет их в одно приложение. Локальная тестовая сборка получает временную подпись, которая не подходит для стабильных обновлений.

Для распространения используйте `./release.command` с постоянным сертификатом автора. Скрипт отказывается выпускать DMG с временной подписью и проверяет сертификат обеих архитектур. Порядок создания репозитория, настройки подписи и выпуска — в [DISTRIBUTION.md](DISTRIBUTION.md).

Исходники лежат в `Source/`, проверки — в `Tests/`. В `Packaging/` находятся оформление DMG и необходимые библиотеки с отдельными лицензиями. Готовые изображения включены; Pillow нужен только для повторной генерации оформления. Тонкий значок «а/я» рисуется системным шрифтом macOS и автоматически адаптируется к светлой или тёмной строке меню. Значки приложения в Finder и установщика сохранены.

Локально проверены универсальная компиляция, подпись постоянным сертификатом автора для обеих архитектур и 65 проверок логики на Apple Silicon. Проверены подпись приложения внутри образа, контрольная сумма DMG и совпадение идентичности двух разных версий, подписанных одним ключом. Запуск на Intel, вход в систему с автозапуском, реальное сохранение разрешения при подписанном обновлении и выполнение GitHub Actions требуют отдельной проверки. Исходная версия работала у автора после ручной выдачи разрешения.
